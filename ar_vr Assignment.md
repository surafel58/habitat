**Assignment: Build an AR/VR Powered E-Commerce Experience**

**Objective**  
Design and develop a modern AR/VR-enabled web platform that enhances online shopping through immersive product visualization and interactive experiences.

Choose Any One Domain

**Reference Implementations (For Inspiration Only)**

You may refer to the following existing prototypes built by Grovyn for domain understanding:

**Real Estate Prototype:** https://real-estate.grovyn.in/

**Jewelry E-Commerce Prototype:**  

These are basic reference implementations. Candidates are encouraged to significantly improve upon them in terms of design, user experience, AR/VR capabilities, innovation, product thinking, and overall execution.

Evaluation will favor original ideas and superior implementations rather than replication of the existing prototypes.

**Option 1: Real Estate**   
Create an AR/VR property showcase platform where users can:  
• Explore properties through virtual tours  
• View floor plans in 3D  
• Place property models in real-world environments using AR  
• Compare multiple properties  
• Schedule inquiries and site visits

**Option 2: Jewelry E-Commerce**  
Create an AR/VR jewelry shopping platform where users can:  
• Virtually try rings, necklaces, bracelets, and earrings  
• View products in 360°  
• Customize materials and gemstones  
• Save and share favorites  
• Complete purchases online

**Option 3: General E-Commerce**  
Create an AR/VR shopping platform where users can:  
• Visualize products in their space using AR  
• Explore products in immersive VR showrooms  
• View products in 3D  
• Manage cart and checkout  
• Receive personalized recommendations

Minimum Requirements  
• Responsive web application  
• Modern UI/UX design  
• Authentication system  
• Product or listing management  
• AR or VR integration  
• 3D product visualization  
• Search and filtering  
• Wishlist functionality  
• Contact or inquiry system  
• Deployment on a public URL

Suggested Tech Stack  
Frontend: React / Next.js  
Backend: Node.js / Express  
Database: MongoDB / PostgreSQL  
AR/VR: Three.js, React Three Fiber, WebXR, Babylon.js  
Authentication: JWT / Firebase Auth  
Deployment: Vercel, Netlify, AWS, or Render
